# Code & PR Reviewer

## Role

The Code & PR Reviewer helps maintain the quality, reliability, and consistency of contributions made to OSDC repositories.

## Responsibilities

- Review Pull Requests before they are merged.
- Check whether the contribution follows project guidelines.
- Look for bugs, unnecessary complexity, and potential issues.
- Suggest improvements in a constructive way.
- Check code readability and maintainability.
- Verify that documentation is updated when necessary.
- Encourage contributors to write meaningful commit messages and PR descriptions.
- Help beginners understand the review process.
- Approve PRs when they meet the project's requirements.

## Goal

Help contributors improve their work while keeping OSDC projects reliable and maintainable.
