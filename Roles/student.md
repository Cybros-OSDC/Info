# OSDC Student / Member

## Role

Students and members are the heart of OSDC. Members participate, learn, collaborate, and contribute to open-source activities.

## Responsibilities

- Participate in OSDC events, discussions, and projects.
- Contribute to open-source projects whenever possible.
- Learn and follow Git and GitHub workflows.
- Complete assigned tasks responsibly.
- Ask for help when facing difficulties.
- Help other members when possible.
- Report bugs and suggest improvements.
- Respect project guidelines and maintain good communication.
- Share knowledge and learning resources with the community.

## Goal

Learn, contribute, collaborate, and help create a healthy open-source community.
