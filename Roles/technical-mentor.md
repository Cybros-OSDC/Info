# Technical Mentor

## Role

The Technical Mentor helps students and contributors understand technical concepts, solve problems, and become confident contributors.

## Responsibilities

- Help members with technical questions.
- Guide beginners through Git and GitHub.
- Help contributors understand project structure and workflows.
- Explain concepts rather than simply providing solutions.
- Help members debug problems.
- Direct members to useful documentation and resources.
- Support contributors during events and open-source projects.
- Encourage independent problem-solving.
- Escalate complex issues to the Coordinator or another senior contributor when necessary.

## Goal

Help members learn, solve problems independently, and become better open-source contributors.
